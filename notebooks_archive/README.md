# Archivo de notebooks

Este directorio preserva notebooks que no forman parte del flujo canónico.
No deben editarse ni ejecutarse como fuente de resultados finales.

- `duplicates/`: copias o variantes reemplazadas por un notebook canónico.
- `legacy/`: análisis anteriores o auxiliares no priorizados.
- `exploratory/`: pruebas puntuales y experimentos sin integrar.

El flujo activo se encuentra en `notebooks/`; la correspondencia completa está
en [REORGANIZATION_PLAN.md](../REORGANIZATION_PLAN.md).
