# Salidas históricas de notebooks

Este directorio contiene productos derivados que antes estaban mezclados con
las libretas activas. No forman parte del pipeline canónico ni deben usarse
como fuente de resultados finales.

- `figures/`: visualizaciones históricas y variantes descartadas.
- `tables/`: tablas, archivos intermedios y exportaciones históricas.
- `legacy/`: código auxiliar sustituido por los módulos de `src/`.

Los productos activos viven en `results/figures/<análisis>/` y
`results/tables/<análisis>/`.
